# 🔐 Privacy Policy

Protecting user security, privacy, and trust is our highest priority in developing this bot. This document is designed to fully clarify how user data is collected, stored, and used.

---

### 🛡️ 1. Infrastructure and Data Security
For data storage, we utilize the powerful PostgreSQL database. It is well known in the tech world that PostgreSQL, as one of the most advanced and reliable database management systems, provides the highest level of speed, stability, and data security.

All stored data is used solely to ensure bot security and prevent suspicious activities or potential abuse, maintaining a safe and stable environment for all users.

---

### 📊 2. Stored Data and Purpose of Collection
The information stored in the bot's database is strictly limited to the following:

* 🆔 User ID: Used for unique user identification on Telegram and access management.
* 👤 Username: Used for communication and support if necessary.
* 🏷️ Full Name: Used to personalize the user experience within the bot environment.
* 📅 Join Date: Used to determine user seniority and offer better services to long-term users.
* ⏱️ Last Seen: Used for statistical analysis of user satisfaction and to evaluate whether the bot's tools meet user needs effectively.

---

### 🖼️ 3. Handling of Files and Tool Inputs
* Images and Documents: All files uploaded for tools such as Background Removal or Image to PDF Conversion are processed only in real time. Immediately after delivering the output, they are permanently deleted from server memory and are never stored.
* Text Inputs: Data related to QR Code generation and Date Conversion is processed instantly and is never permanently recorded.

---

### 💬 4. Feedback and Reviews
Information submitted in the feedback section (such as email and message content) is strictly used to evaluate service quality and respond to your inquiries. It will never be shared with third parties or outside organizations.

---
*By using this bot, you agree to the terms outlined in this Privacy Policy.*
